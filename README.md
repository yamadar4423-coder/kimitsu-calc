# 気密計算 C値（JIS A 2201 準拠）

住宅等の気密測定データから **C値（相当隙間面積）** を計算する、スマホ対応のWebアプリです。
測定した「圧力差 ΔP」と「通気量 Q」を入力すると、JIS A 2201:2017 に基づいて自動計算します。

## 使い方

1. 延床面積 S（m²）を入力
2. 測定データ（3〜10点・初期5点）の ΔP・Q を入力
3. 「計算する」を押す

- **温度（室内・外気）**：どちらも任意入力。入力すると空気密度 ρ を `ρ = 1.293 × 273.15 /(273.15 + t)` で温度補正し、補正後のρと使った温度を画面に表示。**外気を優先**し、外気がなければ室内を使う。両方未入力なら標準値 1.2 kg/m³。温度によるC値への影響は数%程度。
- **決定係数 R² の合格閾値**：任意に変更可（初期値 0.98）。この値以上で「合格」判定。
- **測定回**：任意入力。何回目の測定かを結果・保存画像に表示。
- **一括リセット**：圧力 ΔP・通気量 Q の入力をまとめてクリア（延床面積・室温・閾値・測定回は保持）。
- **入力の自動保存**：入力した値はこの端末の中（ブラウザの保存領域）だけに自動で保存され、画面を閉じたりスマホが画面を読み込み直したりしても残る（外部へは送らない）。開き直すと「前回の入力（日時）を戻しました」と表示し、計算済みだった場合は結果も出し直す。
- **全部消す（次の現場へ）**：延床面積・温度・測定回・ΔP・Q をまとめて消す（確認あり。R² の合格閾値は設定なので残す）。
- **古い結果を残さない**：計算後に入力を変えたり、入力エラーで計算できなかったりすると、前の結果を画面から消す。「計算する」で出し直す。
- **結果を画像で保存**：計算結果カードをPNG画像として書き出し（html2canvas利用）。

## 計算する内容

- C値（相当隙間面積）
- 総相当隙間面積 αA
- 隙間特性値 n（妥当性チェック付き）
- 通気率 a
- 決定係数 R²
- 回帰グラフ（両対数）

## 計算式（JIS A 2201:2017）

- 通気特性式：`Q = a・ΔP^(1/n)`（両対数の最小二乗法で a・n を算出）
- 9.8Pa時の通気量：`Q9.8 = a・9.8^(1/n)`
- 総相当隙間面積：`αA = 0.627・√ρ・Q9.8`（cm²、ρ=空気密度・既定1.2）
- C値：`C = αA / S`（cm²/m²）。**小数点2桁・四捨五入**で表示（規格は小数点1桁。改善の伸びしろに見当をつけるための独自の設定）

## 技術メモ

- 単一HTMLファイル（HTML / CSS / JavaScript 内蔵、外部依存なし）
- **完全オフライン動作**：計算・グラフ・「結果を画像で保存」まですべてオフラインで完結（html2canvas はHTMLにインライン埋め込み済み）
- iPhone等のスマホ最適化、ホーム画面に追加でアプリ風に使用可

※計算結果は参考値です。正式な判定は測定機関の値をご確認ください。
